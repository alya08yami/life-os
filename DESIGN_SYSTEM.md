# LIFE OS — Design System

## Направление
Premium Editorial Minimalism: спокойный визуальный каталог с фотографией как главным ориентиром. Референс пользователя задаёт композицию и настроение; фирменные элементы и проприетарные шрифты не копируются.

Палитра немного усилена для читаемости небольшого текста. Ни градиентов, ни декоративных разноцветных состояний. Ошибка — отдельный сдержанный semantic token.

Шрифты: Cormorant Garamond Regular для заголовков, Manrope Regular/Medium для UI. Локальные файлы с лицензиями OFL, без runtime CDN. Заголовок 30/36; карточка 15/21; UI 13/19; подпись 12/18. Мелкий текст никогда не light. Системный font scaling не отключать.

Отступы: 4, 8, 12, 16, 20, 24, 32. Базовый gutter 16–24, gap grid 10–12. Радиусы: control 12, изображение/карточка 16, sheet 24. Минимальная зона нажатия 44×44, stroke icons 1.5. Тени только у модального sheet, разделители в остальных местах.

## Композиция
Главная: центрированный LIFE OS, menu слева, search справа; ровно две колонки одинаковых category tiles. Название по центру снизу, без счётчиков и описаний. Небольшой доступ к Inbox сохраняется в нижней навигации. Ни приветствий, ни лозунгов, ни hero-banner.

Уточнение по второму референсу: основные восемь категорий используют компактные горизонтальные фото-плитки; serif-подпись в отдельной нижней области без градиента. Под ними — небольшая строка «Мои дела / Входящие» и быстрые действующие маршруты. Скрытие категорий доступно в настройках. Счётчики на category tiles по-прежнему не используются.

Хотелки: центрированный section header, back/add, горизонтальные filter chips, компактная сортировка, две колонки ProductCard. Фото преобладает, heart — отдельная доступная кнопка. Для карточек без фото — честное нейтральное состояние, без подстановки фото другого товара.

Деталь товара: крупное изображение, serif-название, бренд/модель, свойства, цена с происхождением и датой при наличии, список реальных предложений. Стрелка снижения появляется только при сопоставимом previous/current offer для одной currency/variant. Ручная цена не выдаётся за минимальную найденную. Отсутствующие сведения не выдумываются.

## Демо и ограничения
Демо-каталог — отдельные immutable fixtures и отдельное session-состояние избранного. Переключатель «Демо / Мои» всегда виден. Демо не записывается в Repository, не индексируется личным поиском и не выдаётся за актуальные цены. В демо нет переходов в вымышленные магазины и имитации успешного сохранения.

Личные товары, favorite, фильтры, сортировка и CRUD работают локально. Добавление внутри хотелок фиксирует тип product и category shopping: повторного вопроса «куда сохранить» нет. В sheet доступны реально поддержанные ручной ввод, URL и галерея; AI/камера помечаются недоступными до реализации, не показывают фиктивного успеха.

## Состояния и производительность
Skeleton при загрузке, короткий empty state, error с Retry без потери записей. Catalog grids — FlatList numColumns=2 с windowing и стабильными keys. expo-image использует memory-disk cache; локальные grid assets ограничены 640 px, пользовательские новые изображения получают thumbnail. Detail может открывать исходник; grid не читает его при наличии thumbnail. Старые записи без thumbnail показывают нейтральный preview до обновления, без скрытой потери исходника.

Доступность: подписи icon buttons, независимое сердце без вложенных кнопок, radio/checked семантика фильтров, keyboard dismiss/focus, safe area, адаптивные sheet и max-width на широком экране. Нативная плавность/доступность подлежат отдельной проверке Android/iOS.
