# Последние изменения интерфейса — 2 ноября 2026

Фото в деталях товара и фильма уменьшены до компактного превью. В каталоге хотелок доступны весы сравнения с зелёной отметкой и анимацией, выбранные товары открываются через нижнюю панель. В каталоге фильмов есть отдельные быстрые трейлеры и разные иллюстрации к примерам.

Здоровье открывается сеткой шести категорий; каждая содержит примеры. Гардероб разделён на сезоны, поддерживает фото/пакетный импорт вещей и сохранение выбранных вещей в образ. Работа — доска идей. Питание в этом обновлении не менялось.

На главной долгий тап включает быстрое покачивание, скрытие и перетаскивание с сохранением порядка. Изображения имеют прямые углы.

Поездки показывают места компактным списком. Ссылки Google Maps разбираются локально; сортировка по прямому расстоянию запрашивает геопозицию по кнопке и не отправляет её на сервер. Фото и расширенные данные Google требуют серверного `GOOGLE_PLACES_API_KEY`, включённого Places API (New) и входа в аккаунт. Без настройки доступно ручное сохранение ссылок/названия/своего фото. Native камера/геолокация и drag требуют проверки на устройстве.

# LIFE OS

Персональный органайзер на Expo / React Native / TypeScript. Личные записи работают локально без AI; сервер нужен для аккаунтов, явного общего доступа и внешних интеграций.

Карточки: задачи, покупки, заметки, фильмы/сериалы, рецепты, товары, места, поездки, одежда/обувь/аксессуары, образы, комнаты, интерьер, техника, сценарии, списки, проекты, идеи и материалы. Медицинские записи находятся в отдельном зашифрованном хранилище.

Поддержаны связанные задачи, повторения и история выполнения, календарь рецептов, перенос ингредиентов в покупки, сценарии, ручные предложения магазинов, повторная покупка, поиск, теги, избранное, архив/корзина/восстановление, настройка главной, резервные копии, RU/UK/EN и две темы. Демонстрационный каталог отделён от личных данных.

## Запуск

Node.js 24 и pnpm 11:

```sh
pnpm install --frozen-lockfile
pnpm build:web
pnpm preview
```

Открыть [LIFE OS](http://127.0.0.1:8081). `pnpm preview` запускает готовый web export и настоящий локальный API на 8787. На Mac можно запустить `./preview-web.command`: launcher также находит Node из окружения Codex. На Windows — `preview-web.cmd`.

Для разработки: `pnpm server` и в другом терминале `pnpm web`. Web-запросы `/api` идут через локальный proxy. Локальный API слушает только loopback.

## Данные и аккаунты

Офлайн-библиотека сохраняет прежнее хранилище `life-os-v1` в IndexedDB и `life-os.db` на телефоне. У каждого серверного аккаунта отдельная локальная библиотека. В разделе аккаунта можно явно скопировать офлайн-записи без удаления оригиналов. Это не облачная синхронизация. Сессия находится в памяти, истекает через час и не переживает перезагрузку страницы.

Сервер сохраняет аккаунты, пространства, опубликованные копии и учёт AI в `.local/life-os-server.sqlite`. Код создания аккаунтов — в `.local/server-setup-code`, появляется при первом запуске. Эти файлы исключены из Git. Общий доступ получают только принятые участники; личные карточки публикуются отдельно по явному действию.

Медицинское хранилище защищено собственной парольной фразой (минимум 12 символов). Пароль не сохраняется и не восстанавливается. Без него зашифрованную резервную копию открыть нельзя. Обычная библиотека не зашифрована этим паролем; выход из аккаунта не стирает её с устройства.

## Интеграции

Настройки сервера приведены в `.env.example`. Ключ OpenAI, модель и тарифы, TMDB token задаются только на сервере. В этой поставке ключи не настроены: интерфейс сообщает о недоступности, сохраняет оригинал и позволяет заполнить карточку вручную. AI запускается после явного согласия на отправку выбранного содержимого; результат требует проверки. Карты открываются официальными Google Maps URL.

Android/iOS содержат адаптеры SQLite, файлов, камеры, локальных уведомлений и приёма Share. Нужна development build; JS export не заменяет проверку разрешений и работы на физическом устройстве. Публичный облачный backend, полная синхронизация личных данных, коммерческие каталоги цен и платежи не развёрнуты.
