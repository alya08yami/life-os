# LIFE OS

[Open LIFE OS on your phone](https://alya08yami.github.io/life-os/)

Published browser version of the personal organizer: editable example cards, wishlist comparison, recipes, films, travel lists, wardrobe and outfits, ideas, tasks, and health categories.

Records stay in the browser on the current device. This public preview does not upload personal records to GitHub. AI, external catalog services and shared spaces require a separately hosted API and are unavailable in this static preview.

This repository contains the ready-to-run web build. Development source, credentials, local databases, and runtime files are not included.
