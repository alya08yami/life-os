5 ноября 2026. Код приложения не менялся. Макеты: `docs/mockups/stage5-*.png`.

Проверка шла по коду и по веб-версии в теме Soft Future (390×844) на демонстрационных данных. Ваши настоящие записи хранятся на устройстве, я их не видел. Скриншотов к сообщению не было, сравнивал с текущими экранами.

## Часть 1. Отношения — что есть сейчас

**Код:** один компонент `Relationships` в `planner/Lists.tsx`.

**Данные:**
- Каждая запись: тип `relationship`, вкладка в поле `data.category` («Идеи» / «Секс» / «Ссоры» / «Подарки»).
- Используемые поля: `title`, `status`, `completedAt`.
- Поля `notes`, `createdAt`, `archivedAt` у записи есть, но этот экран их не показывает.

**Действия — одинаковые во всех четырёх вкладках:**

| Действие | Как сейчас |
|---|---|
| Добавить | «+» в шапке → строка ввода над списком |
| Отметить | Нажатие на сердечко → `mark(...,'complete')` + всплывашка «Отменить». Повторное нажатие возвращает запись в список. |
| Изменить | Только **долгое нажатие** на текст → правка названия прямо в строке |
| Выполнено | Сворачиваемый блок со счётчиком и датой выполнения |
| Вкладка | Запоминается при возврате (`relationships.tab`) |
| Архив, удаление, заметка | В этом экране нет. Есть в общей карточке записи (открывается через поиск), но из «Отношений» туда не попасть. |

**«Ссоры» и «Подарки» сейчас — такой же чек-лист с сердечком.** Дат создания, заметок, цен и ссылок в списке нет. Демо-данные есть только для «Идей».

**Визуальные проблемы:**
1. Сердечки залиты ярко-розовым `#e88eac`. Активная и выполненная запись отличаются только цветом, и не-выполненная выглядит уже «отмеченной».
2. Нажимается только сердечко. Нажатие на текст ничего не делает, правка спрятана в долгом нажатии.
3. Все вкладки выглядят одинаково, у каждой нет своего характера.
4. Блок «Выполнено 0» показывается и в пустых вкладках.
5. В веб-версии строка ввода получает чёрную рамку фокуса.

**Приватность:**
- Общий **Поиск** без запроса показывает **все** записи приложения подряд, включая «Секс».
- В уведомлениях, на главной и в превью плиток записей «Отношений» нет.
- Во внешние сервисы записи сами не уходят. Распознавание `/ai/recognize` срабатывает только когда вы сами добавляете что-то через «+ → распознать».

## Часть 2. Покупки и желания — что есть сейчас

**В приложении две отдельные системы товаров.**

| | A. Раздел «Покупки и желания» | B. Старый слой «Мои дела» |
|---|---|---|
| Откуда попасть | Плитка на главной → `/wishlist` | Товары в «Мои дела» |
| Код | `planner/Catalogs.tsx` (`Shopping`, `ProductCard`), карточка — `planner/Screen.tsx`, форма — `planner/Editor.tsx` | `/product/[id]` (`ProductDetailScreen`, `ProductHero`), `/compare-products` |
| Данные | Объекты планировщика `product` | Отдельный каталог («Базовая рубашка», «Кожаная сумка»…) |
| Сравнение | **Нет** | Есть |

- **Сравнение товаров работает только со слоем B** и не видит товары из «Покупок и желаний».
- `WishlistScreen.tsx` нигде не подключён (мёртвый код).

**Раздел A:**
- **Вкладки:**
  - «Все» — все товары, включая купленные;
  - «Желания» — товары с сердечком (`favorite`);
  - «Списки» — поле «Название списка», фильтр по точному совпадению `data.list`;
  - «Куплено» — `status==='completed'`.
- **Цена:**
  - «от N» — минимальная из подтверждённых предложений (`comparableOffers`: та же модель, та же валюта, https, сортировка по цене), иначе `data.price`;
  - скидка — поле `discount` в %;
  - **истории цен нет.**
- **Карточка товара:**
  - фото, название, бренд и модель, цена, цвета, размеры;
  - «Где дешевле» — предложения со ссылками;
  - «Открыть магазин»;
  - «В желаниях»;
  - иконки: закладка, «Куплено», «Поделиться».
- **Форма:**
  - способы добавления «Ссылка / Скриншот / Фото / Название»;
  - поля: название, список, бренд, модель, вариант, цена, валюта, ссылка, предложения магазинов, заметка, вложения, уведомления;
  - проверка на дубликат.
- **Поиск** в шапке ведёт в общий поиск. Внутри раздела есть состояние фильтра `shopping.query`, но поля для него на экране нет.

**Проблемы:**
1. Раздел «заморожен», поэтому в Soft Future он светлый со **старой белой нижней панелью**. Это единственный экран, где панель не тёмная.
2. В карточке списка нет фото (хотя у товаров они есть), свободное место справа не используется.
3. Название повторяется в карточке товара три раза: шапка, заголовок, «бренд модель».
4. **Закладка «Сохранить» ничего не делает** — только показывает «Товар сохранён».
5. Иконки действий без подписей, непонятно, что «✓» означает «Куплено».
6. «Списки» — пустое текстовое поле вместо списка ваших списков.
7. Демо-цены в ₽.

## Часть 3. Дизайн-план

### Общее для двух разделов

- **Поверхность.** Молочная плотная карточка-список: `rgba(251,249,250,.94)`, радиус 18, тонкая граница 6 %, мягкая тень `shadows[1]`. Без размытия под строками.
- **Строки.**
  - Минимальная высота 48 (зона касания ≥ 44).
  - Отступы 12–14.
  - Разделитель 1 px с отступом до текста.
  - Текст Inter 14.5 / 21, переносится полностью, не обрезается.
- **Переключатель вкладок.**
  - Существующий `SoftSegmentedTabs`: подложка скользит, высота 38, текст 13.
  - Активная вкладка «Отношений» подкрашивается цветом вкладки.
  - Высота не меняется при переключении.
- **Анимации — только существующая система:**
  - `FadeRise` — появление;
  - `SwipeableRow` и `listReflow` — перестроение;
  - мягкое нажатие;
  - заполнение иконки за 220 мс (с «уменьшить движение» — сразу).

### Отношения (макеты 1–4)

| Вкладка | Символ (lucide, уже в проекте) | Цвет | Отметка |
|---|---|---|---|
| Идеи | контурное сердце | пыльная роза `#B08196` | заливается; блок «Выполнено» |
| Секс | контурное пламя | сливово-розовый `#8E5F79` | заливается; блок **«Попробовали»** (то же поле `status`) |
| Ссоры | облачко разговора | серо-графитовый `#6F6876` | **без чекбокса**; блок «Обсудили» (см. вопрос 2) |
| Подарки | подарок | пыльная терракота `#A57D72` | блок **«Подарено»** |

- **Нажатие на запись** открывает существующую общую карточку записи: название, заметка, архив, удаление с подтверждением. Новых полей нет.
- **Долгое нажатие** — как сейчас, быстрая правка названия.
- **Свайпы** (компонент этапа 4) — в «Идеях», «Сексе» и «Подарках»:
  - вправо — отметить;
  - влево — «Изменить», «В архив».
  
  В «Ссорах» свайпа «Выполнено» нет.
- **«Ссоры» читаются как записи:**
  - название;
  - дата создания;
  - 1–3 строки заметки серым.

  Отдельной кнопки «Выполнено» нет.
- **«Подарки»:** вторая строка — заметка, если есть. Цену и ссылку добавлю только с вашего разрешения — это новые поля (вопрос 3).
- **Мелочи:**
  - пустая вкладка показывает спокойную подсказку без «Выполнено 0»;
  - строка ввода без чёрной рамки.
- **Приватность «Секса» (вопрос 1):**
  - убрать эти записи из общего поиска без запроса;
  - при запросе показывать только название раздела «Отношения» без текста;
  - в уведомления и на главную они не попадают и сейчас — оставляю так.

### Покупки и желания (макеты 5–6)

- **Снять «заморозку»** только с визуала:
  - тёмная нижняя панель Soft Future;
  - молочный фон и типографика Soft Future.
  
  Расчёты, сортировки, ссылки и правила выбора предложений не трогаю.
- **Строка товара** — в одной карточке-списке, ≈ 64 px:
  - фото 48×48 **только если оно есть**, иначе текст начинается от края;
  - название до 2 строк;
  - цена 16/650 — главный акцент;
  - скидка — маленький спокойный зелёный бейдж;
  - сердечко 44×44 справа;
  - без цены — «Цена не указана» серым;
  - купленный товар — галочка «Куплено» и приглушённая цена.
- **Вкладки** те же четыре. В «Списках» вместо пустого поля — чипы ваших существующих списков из `data.list` (фильтр тот же).
- **Карточка товара:**
  - название один раз;
  - «бренд · модель» показывается, только если отличается от названия;
  - фото с радиусом 20;
  - цена и скидка в одну строку;
  - цвета и размеры — компактные кнопки;
  - «Где дешевле» — карточка-список: магазин, цена, лучшая цена зелёным, ›;
  - внизу понятные кнопки с подписями: «В желаниях» (основная), «Куплено», «Поделиться».
- **«Сохранить»** не работает (вопрос 4).
- **Форма** (оформление, поля и поведение те же):
  - поля группами («Основное», «Цена и магазины», «Заметка»);
  - высота полей 44;
  - ошибки — текстом под полем;
  - черновик не теряется при случайном закрытии — спросить «Закрыть без сохранения?» (вопрос 5).
- **Сравнение товаров** (вопрос 6): сейчас работает только со старым каталогом.

### Риски

- **Снятие заморозки** затронет экраны, которые раньше были неизменны во всех темах. Проверка:
  - попиксельно для 5 других тем: там вид «Покупок» останется прежним;
  - функциональный тест всех вкладок, карточки и формы в Soft.
- **Переименование блоков** («Попробовали», «Подарено», «Обсудили») — только подписи. Данные те же, отмена работает как раньше.
- **Свайп в «Отношениях»** рядом с долгим нажатием: долгое нажатие остаётся правкой названия, свайп работает только по горизонтали (пороги этапа 4).

## Часть 4. Аудит остальных разделов (Soft Future)

| Раздел | Что выбивается | Предложение без изменения логики | Приоритет |
|---|---|---|---|
| Все разделы | Заголовок то слева крупно (Здоровье, Питание, Поездки, Фильмы, Гардероб), то по центру (Работа, Родители, Регулярные, Доходы, Отношения) | Один стиль шапки | **Высокий** |
| Работа | Своя нижняя панель («Дела» вместо «Уведомлений»); названия заметок обрезаны в 3 колонках («Здоро…», «PVT p…») | Общая панель; 2 колонки или список | **Высокий** |
| Поездки | Пустые серые заглушки фото у каждого места | Без заглушек: иконка-точка или ничего | **Высокий** |
| Здоровье | Две полосы вкладок подряд; иконка-скрепка у лекарств непонятна; «Заболевания» впритык | Вторая полоса — тонкие чипы; иконка таблетки; сократить отступы | Средний |
| Гардероб | Крупные карточки со свободным местом справа | Сетка 2 колонки с фото | Средний |
| Фильмы | Крупные кнопки «Трейлер» под каждой обложкой, карусель обрезана | Маленькая иконка ▶ на обложке | Средний |
| Дом и уют | Квадратные чекбоксы рядом с сердечками «Отношений» | Круглые отметки как в «Моих делах» | Низкий |
| Регулярные покупки | Длинный плотный список — хорошо; разноцветные «+» шумят | Нейтральный «+», цвет только в статусе | Низкий |
| Доходы и расходы | Насыщенные зелёные ячейки | Приглушить на 30 %, суммы мельче | Низкий |
| Питание | Плотная сетка, хорошо читается | Только радиусы и тени как у остальных | Низкий |
| Родители | Соответствует, коротко | Тот же стиль списка, что у «Отношений» | Низкий |
| Главная | Соответствует утверждённому дизайну | Не трогать | — |

Предлагаю:
- **Этап 5** — «Отношения» + «Покупки и желания» + единая шапка;
- **Этап 6** — Работа, Поездки, Здоровье, Гардероб, Фильмы, остальное — полировка.

## Вопросы на согласование

1. **Приватность «Секса».** Скрыть эти записи из общего поиска, пока нет запроса, а при запросе показывать без текста? Да / нет / иначе.
2. **«Ссоры».** Сейчас у них есть отметка «выполнено» — возможно, у вас там уже есть отмеченные записи. Варианты:
   - (а) убрать отметку из списка, а уже отмеченные показывать в свёрнутом блоке «Обсудили»;
   - (б) оставить отметку, но назвать её «Обсудили» и сделать нейтральной.
3. **«Подарки».** Добавить необязательные поля «Цена» и «Ссылка»? Это новые поля данных, без них показываю только название и заметку.
4. **«Сохранить» в карточке товара** не работает. Убрать кнопку или сделать её «Добавить в список»?
5. **Форма товара.** Добавить вопрос «Закрыть без сохранения?» при случайном закрытии с введёнными данными?
6. **Сравнение.** Оставить как есть (старый каталог) или позже подключить к «Покупкам и желаниям»? Это изменение логики, отдельным этапом.
7. **Ручная связь «Подарок → Покупки и желания»** (кнопка «Перенести в покупки»). Пока только идея, не делаю.
