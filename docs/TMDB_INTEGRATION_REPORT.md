# TMDB в «Фильмах» через Cloudflare Worker — отчёт

5 ноября 2026. Коммит `2f5a6dd`. Изменения — только в Soft Future, раздел «Фильмы».

## Что изучено перед подключением

- **В проекте уже были:**
  - серверный адаптер TMDB в `apps/server` (`/catalog/search`, `/catalog/{movie|tv}/{id}`);
  - сценарий «Распознать / найти» в редакторе (`planner/IntegrationReview.tsx`);
  - экран `/movie-catalog` в старом слое;
  - компонент атрибуции `Credits`.
- **Всё это требует запущенного сервера и входа в аккаунт.** В сборке GitHub Pages и на телефоне без сервера каталог недоступен (`catalog=false`).
- **Новый клиент** использует ваш Worker с тем же форматом ответа, что у серверного адаптера (как в `docs/TMDB_CLOUDFLARE_GUIDE.md`). Сервер и сценарий в редакторе не тронуты, второй серверной интеграции нет.

## Что сделано

- **Клиент `src/catalog/movies.ts`:**
  - **Адрес:** `https://life-os-tmdb.alya-08yami.workers.dev` — публичный адрес в конфигурации, при сборке можно заменить через `EXPO_PUBLIC_CATALOG_URL`.
  - **Запросы:**
    - `GET /search?query=…&locale=ru` — поиск;
    - `GET /movie/{id}` для фильма или `GET /tv/{id}` для сериала по `mediaType` выбранного результата — детали.
  - **Проверка ответа:**
    - пути постеров по шаблону TMDB;
    - трейлер — только ссылка YouTube;
    - год — четыре цифры.
  - **Ошибки:** нет сети, не отвечает (5xx или таймаут 12 с), слишком много запросов (429), неверный запрос (400).
  - **Размеры постеров:** w92 в результатах поиска, w185/w342 в сетке, w500 на странице фильма. Оригиналы не грузятся.
  - **Ключа или токена в клиенте нет.** Запросы к Worker уходят без заголовка `Authorization`.
- **Поиск и добавление (`planner/MovieSearch.tsx`).** «＋ Найти и добавить фильм» внизу списка и «+» в шапке «Фильмов» открывают нижний лист:
  - **Поиск по мере ввода:** пауза 450 мс, от 2 символов, новый запрос отменяет прежний.
  - **Результаты:** постер, название, год, «Фильм / Сериал», оригинальное название.
  - **Автоматического выбора нет, даже при одном результате.** Нажатие на результат загружает детали и показывает предпросмотр: постер, год, жанры, длительность, описание. Добавляет только кнопка «Добавить в коллекцию».
  - **Сохраняется:** название, год, описание, жанры, длительность, трейлер (если есть), `catalogId` (`movie:157336` / `tv:90228`), `tmdbId`, `posterPath`, `posterUrl` (w500), `catalogSource: TMDB`.
  - **Фильм уже в коллекции** (тот же `catalogId`) — пометка «Уже в коллекции» и кнопка «Открыть», дубликат не создаётся.
  - **«Добавить вручную, без каталога»** открывает прежний редактор.
  - **Состояния:** подсказка, загрузка, «Ничего не найдено», «Нет подключения к интернету» с кнопкой «Повторить», «Каталог не отвечает», «Слишком много запросов».
- **«Найти постер» для уже добавленных фильмов:**
  - кнопка на странице фильма показывается **только если у фильма нет никакой обложки** (ни вашего вложения, ни постера);
  - поле поиска заполнено названием фильма;
  - после выбора — сравнение «Сейчас → Постер TMDB» и «Сохранить постер»;
  - **записываются только** `posterUrl`, `posterPath`, `catalogId`, `tmdbId` — название, год, оценка, заметка, статус и вложения не трогаются.
- **Атрибуция TMDB:**
  - логотип (меньше и бледнее логотипа LIFE OS) и фраза «This product uses the TMDB API but is not endorsed or certified by TMDB.»;
  - **показывается:** в листе поиска и на странице фильма, данные которого взяты из TMDB.
- **Дизайн Soft Future не изменён:**
  - сетка 2:3 — 4 колонки (81 px на 390, 77 px на 375) и 3 колонки на 320 px (88 px);
  - страница фильма, оценка, трейлер — как на этапе A.
- **Без интернета:**
  - сохранённые фильмы, их данные, оценки и заметки работают как раньше;
  - постеры, если браузер или телефон не успел их закэшировать, заменяются спокойной плиткой с названием.

## Ограничения и что осталось

1. **Новая сборка ещё не опубликована на GitHub Pages.** Живые запросы и постеры проверены со страницы опубликованного LIFE OS, но сам новый интерфейс поиска там появится только после публикации. Опубликую по вашему разрешению и повторю проверку на живом сайте.
2. **Сценарий «Распознать / найти» в редакторе** по-прежнему ходит через `apps/server`. В Soft Future «Фильмы» теперь добавляются через новый лист, поэтому этот сценарий там не нужен. В других темах я его не менял, как вы просили.
3. **Кэша постеров для работы без интернета** в приложении нет (это потребовало бы новой библиотеки). Офлайн показываются плитки с названием.
4. **Worker** разрешает браузерные запросы только с вашего GitHub Pages и с localhost:8081. Приложение на телефоне заголовок Origin не отправляет, ему это не мешает.
