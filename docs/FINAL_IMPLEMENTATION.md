# Детали карточек и новые разделы — 2 ноября 2026

- Деталь товара: превью 120×96, полный размер открывается отдельным нажатием. Деталь фильма: иллюстрация 100×90. Каталог товаров: названия по центру, отдельные весы внизу справа на фото, зелёный selected/check и spring animation, передача выбранных ID в сравнение.
- Здоровье: шесть плиток категорий вместо общей полосы; по пять новых примеров каждой категории, включая документы. Старые личные и защищённые записи сохранены.
- Фильмы: пять разных локальных иллюстраций по сюжету (не официальные постеры); проверенные ссылки на трейлеры доступны из каталога. Обновляются только untouched примеры версии 1.
- Поездки: компактные строки с названием/фото/ссылкой; вставка Maps URL извлекает название и координаты pin (не центр viewport). Сортировка по прямому расстоянию после явного разрешения; координаты пользователя остаются на устройстве, неизвестные места в конце.
- Реальный серверный Google Places adapter: authenticated endpoint, rate limit, фиксированные официальные endpoints, безопасное разрешение коротких Google ссылок, явный выбор результата, временное отображение фото/авторов. Требует `GOOGLE_PLACES_API_KEY` и аккаунта. Ключ не настроен, live Google данные не проверены; adapter проверяется синтетическим fetch. Фото не записываются в local attachments/backup. [Google Places](https://developers.google.com/maps/documentation/places/web-service/place-details), [Photos](https://developers.google.com/maps/documentation/places/web-service/place-photos).
- Гардероб: плитки четырёх сезонов, фото с камеры, импорт до 10 фото, ручной выбор своих вещей и сохранение outfit. Это не AI распознавание или автоматический подбор.
- Работа: доска идей с простым вводом названия/текста. Прежние проекты и материалы сохранены в библиотеке/поиске.
- Главная: прямые углы плиток/изображений, покачивание вдвое быстрее, drag-and-drop с сохранением порядка; скрытие и восстановление остаются.

Питание не менялось. Native geolocation adapter использует только foreground permission; необходима новая native build и проверка на устройстве. [Expo Location](https://docs.expo.dev/versions/latest/sdk/location/).

# LIFE OS — результат полной доработки, 2 ноября 2026

Все категории карточек из задания получили типизированное локальное хранение, формы, просмотр и обычный жизненный цикл. Приложение продолжает работать без внешних ключей. Коммерческий облачный продукт целиком не объявляется завершённым: ниже отдельно указаны реализованные функции и оставшиеся внешние компоненты.

## Карточки и связи

| --- | --- |

| Еда | Рецепт, шаги, ингредиенты с явными количествами, порции, масштабирование без выдуманных значений, время, заметки, план по датам, выбор/коррекция покупок, защита от дублей |

Связанные самостоятельные записи не удаляются каскадно. Сохранение материала не создаёт задачу автоматически. Повторения сохраняют историю и следующую дату в той же задаче. Напоминания используют явное включение и тихие часы; срок сам по себе не означает выданное разрешение ОС.

## Общие механизмы

- Контекстное создание, теги, поиск, избранное, темы, RU/UK/EN; настройка порядка/видимости главной.
- Скрытое, архив, корзина, восстановление; безвозвратное удаление требует отдельного действия.
- Переносимые JSON backup с изображениями и зашифрованным vault; импорт объединяет по ID без перезаписи существующих карточек.
- IndexedDB / SQLite schema v1 сохранена. Исходная офлайн-библиотека не очищалась и не мигрировала разрушительно.
- Отдельная локальная библиотека на аккаунт. Явное копирование офлайн-записей сохраняет исходники. При смене аккаунта дерево экранов и открытый медицинский ключ сбрасываются. Локальные библиотеки обычных карточек остаются на устройстве: это разделение приложения, не защита от владельца диска/профиля браузера.

## Реальный сервер и внешние адаптеры

`apps/server` — настоящий локальный HTTP API с постоянным SQLite, scrypt-паролями, хешами токенов, сроком/отзывом сессий, кодом регистрации, ограничениями запросов и правами доступа. Общие пространства: владелец/участник, одноразовое адресное приглашение, принятие/отзыв, явные копии карточек с переносимыми изображениями, исполнитель, завершение/восстановление, повторения, optimistic version. Проверены два отдельных аккаунта и потеря доступа после удаления участника.

AI gateway вызывает OpenAI Responses API только при полной серверной конфигурации. Поддерживает текст/изображения, structured output и доменную валидацию, явное согласие, очередь/ошибки, кэш на пользователя, дедупликацию запросов, дневные ограничения и учёт стоимости. Не использует инструменты модели для действий над данными; результат становится карточкой после проверки. Ключи, модель и реальные тарифы не были предоставлены, поэтому живое распознавание не проверялось. Тесты provider adapter используют синтетический ответ fetch; интерфейсный API-тест проверяет честный `provider_unavailable`.

TMDB adapter делает настоящий поиск и получение выбранной пользователем карточки/трейлера, когда задан серверный token. Без token он недоступен. В интерфейсе добавлены официальные attribution и логотип. Живой каталог не проверялся.

Google Maps открывается через официальные URL без встроенного SDK. Проверены кодирование и предел длины, порядок точек, ссылки/переходы. Живой маршрут и содержимое стороннего сервиса не тестировались.

Удаление серверного аккаунта отзывает сессии и удаляет принадлежащие серверные данные. Оно не является удалённым стиранием офлайн-библиотеки с устройства. Очистка AI результатов не обнуляет учёт потраченных запросов. Экспорт аккаунта и локальная резервная копия — разные действия.

## Медицинское хранилище

AES-256-GCM, PBKDF2-SHA256 600000, случайные соль/nonce, authenticated metadata; зашифрованы и записи, и вложения. Браузер использует Web Crypto, native — Noble с Expo RNG. Тест проверяет совместимость обоих направлений, Unicode, неверный пароль, подмену ciphertext и отсутствие записей в обычном поиске. Ключ native затирается при блокировке; web CryptoKey nonextractable. Блокировка при уходе в фон и после 10 минут.

Не выполнялись внешний криптографический аудит, проверка ОС на реальном устройстве и сертификация медицинского продукта. Нет рекомендаций по лечению, интерпретации анализов или автоматического назначения приёма лекарств.
