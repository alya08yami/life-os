# LIFE OS 1.0 — итоговый отчёт релиза

6 ноября 2026.

- **Приложение:** https://alya08yami.github.io/life-os/
- **Репозиторий:** https://github.com/alya08yami/life-os
  - `main` — опубликованный коммит `da98b78` (исходники + сборка для GitHub Pages);
  - `development` — полная история разработки, исходники соответствуют `2b9a9a1`.

## 1. Аудит перед изменениями

- **Git.** Все коммиты на месте, включая TMDB `2f5a6dd`. Незакоммиченных изменений не было. У локальной папки не было связи с GitHub, а история публичного репозитория отдельная.
- **GitHub Pages.** Сайт публикуется из корня ветки `main`: исходники и собранные файлы лежат вместе.
- **PWA.** Не было ни manifest, ни иконок, ни service worker.
- **Хранение.** Все данные лежат одним состоянием в IndexedDB `life-os-v1` того сайта, где ими пользуются:
  - записи 12 разделов, история «выполнено / куплено», прочитанные уведомления;
  - тема и настройки, порядок разделов;
  - фото и файлы (внутри записей);
  - зашифрованное медицинское хранилище.

  localStorage не используется.
- **Резервная копия** уже была, но:
  - восстановление только добавляло новые записи (изменённые и удалённые не возвращались, настройки не восстанавливались);
  - у файла не было версии формата и даты;
  - вместо удобного выбора файла было поле для вставки текста.
- **Автоматического сброса хранилища нет.** При ошибке чтения данные не перезаписываются.
- **Риск потери данных** найден один, и он не в коде: на iPhone у Chrome, Safari и установленного приложения разные хранилища. Решение — перенос через резервную копию (раздел 10).

## 2. Что сделано

**Хранение и резервная копия**
- **Формат копии `life-os-backup` v1:** версия формата, дата создания, сводка содержимого и полное состояние. Старые копии (без версии) тоже принимаются.
- **«Сохранить копию»:** на iPhone открывается меню «Поделиться» → «Сохранить в Файлы», на компьютере файл скачивается. Показаны дата последней копии и что в неё войдёт.
- **«Восстановить из копии»:**
  - выбор файла и проверка формата;
  - предпросмотр (дата, записи, фото);
  - предупреждение и предложение сначала сохранить текущую копию;
  - замена всех данных одной транзакцией: при ошибке не меняется ничего.

  Прежний режим «Только добавить недостающие записи» сохранён.
- **Миграции.** Добавлен механизм обновления формата данных. Данные или копия более новой версии не перезаписываются и не обрезаются.
- **Переполнение хранилища:** понятное сообщение «Не хватает места в хранилище браузера — запись не сохранена…». Существующие данные не страдают.
- **Постоянное хранилище.** Приложение просит браузер не удалять данные при нехватке места; браузер может отказать.

**PWA для iPhone**
- **Manifest:**
  - `name` и `short_name` — LIFE OS;
  - `display: standalone`;
  - `start_url` и `scope` — `/life-os/`;
  - `theme_color` и `background_color` — графит `#35343D`;
  - иконки 192, 512 и 512 maskable.
- **Иконка** — фирменный градиент главного экрана и надпись «LIFE OS» шрифтом Inter. Новых элементов нет.
- **iOS:**
  - `apple-touch-icon` 180×180;
  - `apple-mobile-web-app-capable`, `-title`, `-status-bar-style`;
  - `viewport-fit=cover`;
  - без автоматического увеличения при вводе текста.
- **Безопасные области.** Нижняя панель и нижние листы отступают от полосы «Домой» на iPhone без кнопки «Домой». Листы поднимаются над экранной клавиатурой.
- **Цвет строки состояния** меняется по экрану: графит на главной, фон темы на внутренних экранах.
- **Service worker:**
  - хранит копию файлов приложения, чтобы оно открывалось без интернета;
  - саму страницу всегда сначала запрашивает из сети (новая версия подхватывается при следующем запуске с интернетом);
  - удаляет кэши старых версий, оставляя одну предыдущую;
  - **не трогает IndexedDB** и запросы к TMDB и другим сайтам.

**Точечная полировка**
- **Тёмная тема:** неактивные пункты нижней панели стали читаемыми (контраст около 4,8:1). Это единственное изменение в пяти других темах; сравнение 125 экранов это подтверждает.
- **Атрибуция TMDB** чуть крупнее и контрастнее, но по-прежнему ненавязчива.
- **Пустые состояния** получили короткие подсказки: общий список, поиск, заметки, уведомления.
- **Остальное** (Soft Future, сетка фильмов, неделя питания, «Отношения», навигация) не менялось: проверено, работает хорошо.

## 10–14. Инструкции

Подробно, с шагами для Chrome и Safari: [docs/IPHONE_INSTALL.md](IPHONE_INSTALL.md).

**Chrome на iPhone (iOS 16.4+):**
1. Откройте https://alya08yami.github.io/life-os/.
2. Нажмите «Поделиться» (справа в адресной строке или «⋯» → «Поделиться»).
3. Выберите «На экран „Домой“» и проверьте, что название — LIFE OS (если есть переключатель «Открыть как веб-приложение», включите его).
4. Нажмите «Добавить».
5. Открывайте иконкой: адресной строки быть не должно.

**Safari:** «Поделиться» → «На экран „Домой“» → «Открыть как веб-приложение» включено → «Добавить».

**Где данные:**
- только на iPhone, в хранилище установленного приложения;
- у Chrome, Safari и установленной LIFE OS **разные хранилища**;
- записи из Chrome сами в приложении не появятся — перенос: копия в Chrome → «Восстановить из копии» в приложении.

**Сохранить копию:** Профиль → Резервная копия → «Сохранить копию» → «Сохранить в Файлы».

**Восстановить:** Профиль → Резервная копия → «Восстановить из копии» → файл → «Заменить данные этой копией» → «Заменить данные».

## 15–16. Ограничения

- **Данные могут пропасть,** если удалить иконку LIFE OS, очистить данные сайтов или если iOS освободит место. Поэтому нужна регулярная резервная копия.
- **Копия не зашифрована.** Постеры TMDB в ней хранятся ссылками, фото примеров — как встроенные картинки приложения.
- **Синхронизации между устройствами нет.**
- **Без интернета** не работают поиск TMDB, загрузка новых постеров, карты и внешние ссылки.
- **В репозитории остались файлы предыдущих публикаций** (старые сборки в корне). Я их не удалял, чтобы ничего не сломать; их можно убрать позже.

## 17. Что нельзя проверить без настоящего iPhone

Все проверки — в браузерной эмуляции (Chromium, мобильные размеры) и во встроенном браузере на Mac.

**Не проверено на настоящем устройстве:**
- пункт «На экран „Домой“» в вашей версии Chrome и iOS;
- запуск без адресной строки;
- вид иконки;
- отступы от выреза и полосы «Домой»;
- поведение клавиатуры;
- меню «Поделиться» → «Сохранить в Файлы»;
- выбор файла из «Файлов»;
- офлайн-запуск;
- цвет строки состояния;
- поворот экрана.
