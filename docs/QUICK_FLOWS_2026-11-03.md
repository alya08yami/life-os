# Weekly calendars and quick-entry update

- Home calendar pages horizontally by week, with arrow controls as an alternative. Exercise is shown once beside its checkbox. Plus replaces the counter and opens habit creation; multiple habits are persistent.
- Shopping catalogue uses compact text rows without product images. Existing product data remains available in details.
- Health opens Medications, then Checkup, then Analyses. Overview removed. Thin pill glyphs replace photos in medication lists and history; the check action immediately records a purchase with the configured package quantity.
- Regular supplies use coloured plus controls. Taps separated by no more than 650 ms form one purchase burst: one/two/three taps store quantity one/two/three. The first timestamp and original undo snapshot are retained. A later burst creates a new history record. Floating quantity feedback animates; sorting waits until tapping finishes so the row cannot move under the finger.
- Food opens Plan. Seven aligned day columns each contain breakfast/lunch/dinner/snack. The same horizontally paged week contains headings and meals, so they move together. Images fill their day-column width. Known example dishes use short plan labels; other dishes can have a custom short label. Saved weekly templates can be named, reapplied and edited. Today/quick cards/Ingredients tab removed. Top-right plus offers dish/recipe/photo actions.
- A scoped navigation history retains section tabs, filters, plan week and selectors when details open. Header back, right-edge back and native hardware back use the same previous-step handler. Legacy detail back handlers also use it. Inactive screens no longer render duplicate undo toasts.
- Finance totals are centered, with the total amount at half its previous size. Tapping a date opens an autofocus decimal keypad field; Enter/Done or blur saves one transaction and displays its currency suffix in the day cell. No separate Add Income/Expense button. Notes plus opens inline text entry with single-save protection.

Validation: 83 domain/integration tests pass. Seven isolated mobile browser scenarios pass, including horizontal wheel/paging, multiple habits/reload, no-image lists, immediate medication purchase, counted regular purchases/history, template transfer/back navigation, decimal input/autofocus/blur persistence and inline notes. TypeScript and web build pass. Phone software keyboard appearance is requested through decimal input mode; physical devices were not directly controlled.
