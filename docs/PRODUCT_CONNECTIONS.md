# LIFE OS — связи между разделами

Дополнение пользователя от 2 ноября: ценность измеряется полезным действием после сохранения, а не количеством карточек. Новые разделы не приоритетнее связей внутри существующих.

В текущем UI-этапе: компактная главная с My tasks/Inbox, настройка видимости категорий; единый просмотр задач и покупок; рецепт → выбор необходимых ингредиентов → обычный список покупок с сохранением ссылки на исходный рецепт. Приложение не угадывает запасы пользователя. Повторное нажатие не дублирует незавершённые ингредиенты того же рецепта.

Следующие поставки:
1. «Разобрать»: multi-select import, один явный запуск, provider quota preview, отдельные результаты каждого файла, исправление неуверенных результатов и массовое подтверждение. До backend нет обещаний распознавания.
2. Compare 2–3 products: обычный код сопоставляет подтверждённые характеристики, variant/currency/shipping; отсутствующие значения видимы. AI-вывод — отдельная opt-in операция с источниками, не выдуманный вердикт.
3. Регулярные дела внутри категорий с агрегированием в My tasks: согласование интервала, timezone, календарная семантика, никаких включённых без согласия уведомлений.
4. «Купить снова»: связь с исходным product, предложение интервала после bought, отдельное подтверждение напоминания.
5. Общие пространства с явным sharing scope и ролями для пары/соседей/друзей, не обязательная family subscription. Личные и медицинские данные приватны по умолчанию.

Приложение поддерживает ежедневный центр дел и обращение по необходимости через каталог. Каталог остаётся основной домашней композицией; actual My tasks находится в одном касании. Мотивационные блоки и фоновый AI не добавляются.
